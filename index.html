检索与训练

面向 39,901 篇论文与专利、193.2 万个 Chunk，构建混合检索与三路 Query；审计高排名训练样本后发现不安全负例率达 42.2%，据此微调 Qwen3-Embedding，使 Chunk Recall@100 从 0.78 提升至 0.86。

Agent 与 Runtime

人机协同标注

针对纯人工标注速度慢、质量不稳定及题目区分度不足的问题，由我提出 LLM 生成候选含义、标注者筛选改写复核的流程；相较纯人工版本，同一批模型平均准确率降低 15.0 个百分点。

实验发现

评测 18 个多模态模型与 3 个文本基线，最佳模型仍落后人类 13.8 个百分点；CoT 与 Few-shot 未带来稳定收益，并揭示信息忽略、过度推断与文化知识不足等缺陷。
